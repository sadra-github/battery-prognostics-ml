# Results

Store experiment outputs here only when they can be reproduced from a documented configuration and permitted data source.

For each experiment, record:

- dataset name, version, and citation;
- target definition and end-of-life rule;
- input features and preprocessing steps;
- train/validation/test split, including battery-level grouping where relevant;
- random seeds, model configuration, and software versions;
- sample counts and metrics such as MAE, RMSE, and R-squared;
- limitations, uncertainty, and known failure cases.

Do not add illustrative or unverified numbers as experimental results. Large outputs, private data, and restricted files should remain outside version control.
